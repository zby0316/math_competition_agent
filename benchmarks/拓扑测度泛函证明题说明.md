## 2. 条件与论证核查

核查中特别确认：

- 拓扑题在使用紧致集闭性及正规性时保留 Hausdorff 假设；商映射的开邻域要求饱和，不能假定任意商映射都开。
- 测度题区分全序列与子列收敛，明确有限测度用于异常集估计或有界截断的积分收敛；给出有符号抵消、集中尖峰及无限测度反例。
- 泛函题区分弱与强收敛、紧与有界算子、上确界范数与 C1 范数；一致有界性和闭图像定理都检查完备性。

背景条件核对采用大学课程资料：[MIT 拓扑速查](https://math.mit.edu/classes/18.786/2024/TopologyPrimer.pdf)、[UCLA 可数性与分离公理](https://www.math.ucla.edu/~sharifi/notes/topology-ch04.html)、[UC Davis 测度论讲义](https://www.math.ucdavis.edu/~hunter/measure_theory/measure_notes.pdf)、[MIT 泛函分析讲义](https://ocw.mit.edu/courses/18-102-introduction-to-functional-analysis-spring-2021/3d4cc88026d44a01f936cd6a0aa995cb_MIT18_102s20_lec_FA.pdf)。这些链接用于相关定义与定理条件核对，不表示讲义中有本集的相同题面或解答。

[build_proof_gap12.py](build_proof_gap12.py) 仅使用标准库，既不联网也不调用模型：

```powershell

```

## 4. 试跑与人工验收方案

首批六题在 `outputs/proof_gap12_pilot6_20261001/`，失败题复跑及剩余六题分别在 `outputs/proof_gap12_fixcheck6_20261001/`、`outputs/proof_gap12_remaining6_20261001/` 完成。共 13 次整题求解；三阶段人工核对记录已归档。以下仅为独立重跑目录示例，会调用模型 API，每道整题可能产生多次底层请求。

```powershell

python main.py --input_file benchmarks/proof_gap12_pilot6_input.jsonl --output_dir outputs/proof_gap12_pilot6_v1_run1
```

每次代码版本或重跑改变时使用新的输出目录，防止断点续跑跳过旧结果。记录提交/工作树版本、`AGENT_VERSION`、模型、题集哈希、并发、耗时和完整 trace；首轮不向代理传入学科标签，以便观察实际分类。

人工复核必须阅读**完整 `final_response` 及必要的推理 trace**，不能仅比较最终结论。按各题四项清单核对，接受其他有效证明路线；禁止因为出现定理名、结论与参考相同或有限数值实验通过就判证明正确。

- **正确**：全部问项得到回答，定理条件满足，关键证明链条完整，要求的反例已验证。
- **错误**：关键推理无效、结论错误、遗漏必要问项，或把所需结论直接当作已知定理引用。
- **待复核**：无法可靠判断的论证或信息不足，记录缺失步骤及疑点，保留为 `null`。

汇总分别报告通过、不通过、待修正及待复核，记录分类、证明遗漏、无效推理、截断和重试耗时。主链有效但含边界表述错误或标量域歧义的答案，严格口径下单列待修正，不计作完全通过；已询问用户验收偏好，未答复时采用此保守默认。数据准备与本地试跑不构成官方得分验证；官方总分仍只有 **69.64/100**。
