# UGMathBench 跨领域高难度诊断集：离线准备记录

## 目的与范围

官方基线只有总分 **69.64/100**，没有逐题日志。此前的 U-MATH 24 题全部与参考答案一致（其中 1 题题面自相矛盾），所以需要一组更能暴露领域和题型弱点的题。这里从 [UGMathBench 数据集](https://huggingface.co/datasets/UGMathBench/ugmathbench) 固定版本 `8ab16f0c131a9b3b52195e64175cb5a8f3881bbf` 的 `v1` 中人工筛选 **26 题 / 14 学科**。原论文把 `level` 作为 1–6 级难度标签；本集仅取 4–6 级：4 级 17 题、5 级 7 题、6 级 2 题。

与 U-MATH 集相比，新增抽象代数、组合数学、复分析、微分方程（含 PDE）、线性代数、数论、概率、逻辑、统计等领域。没有纳入与项目官方 18 领域关联较弱的算术和金融数学。UGMathBench 的领域分类仍不能等同于官方分类；拓扑、泛函分析、测度论等仍缺少直接覆盖。

## 数据质量与筛选

- 原始 16 个学科 JSON 都已下载到被 Git 忽略的 `outputs/ugmathbench_source/`。构建脚本只读取入选题涉及的 14 个文件，固定修订号并逐文件校验 SHA-256。题面、答案和题型保留原文；不翻译，也不改写有争议的参考答案。
- 逐题阅读了入选题面与参考栏；检查 `[ANS]` 占位数等于答案数、答案类型和选项数，排除乱码和缺失字段。对非平凡数值题做了独立计算或符号核对，例如组合数、ISBN 校验位、圆柱相交面积、回归直线、概率矩、船舶方位。**这降低了数据错误风险，但不构成每题的正式数学证明。**
- 排除 `Complex_analysis_0045`：题面要求“所有平衡点”，参考栏只给一个；排除 `Geometry_0080`：按题面将爬升速度计入空速，计算出的地速约 441.28 km/h，与参考 427.352 不一致；排除 `Combinatorics_0013`：题面有乱码与重复句。原始数据集论文也报告了少量坏题，因此后续必须保留人工复核。
- 另外检查了 [HARDMath2](https://huggingface.co/datasets/JVRoggeveen/HARDMath2) 的 211 题。它集中在渐近分析、边界层和非线性 PDE，和当前广覆盖诊断目标不完全相符；抽查时也见到题面缺少极限条件的记录。暂不并入本轮题集，若后续发现 PDE/渐近分析是失分点，再单独做严格复核。

## 题目构成

| idx | 学科 | 题目重点 | 源难度 | 答案栏数 |
| ---: | --- | --- | ---: | ---: |
| 0–1 | 抽象代数 | 子群阶、商环成域 | 6、5 | 1、1 |
| 2 | 代数 | 椭圆拱桥几何建模 | 5 | 1 |
| 3–4 | 多元微积分 | 切平面、柱面面积 | 4、4 | 2、1 |
| 5–6 | 单变量微积分 | 相关变化率、参数曲线弧长 | 5、4 | 1、1 |
| 7–8 | 组合数学 | 错排、递推函数 | 4、5 | 1、6 |
| 9–10 | 复分析 | 开集判别、调和函数 | 6、4 | 1、1 |
| 11–12 | 微分方程 | 冲激响应、对流扩散 PDE | 4、4 | 1、1 |
| 13 | 几何 | 空间向量夹角 | 4 | 1 |
| 14–15 | 线性代数 | 可对角化条件、线性算子行列式 | 4、4 | 1、1 |
| 16–17 | 数论 | ISBN 同余、模 8 幂 | 5、4 | 2、3 |
| 18–19 | 概率论 | 判别式事件、分布的均值与方差 | 4、4 | 1、2 |
| 20–21 | 集合与逻辑 | 区间像及原像、命题等价 | 4、5 | 2、1 |
| 22–23 | 统计 | 置信区间、最小二乘回归 | 4、4 | 2、1 |
| 24–25 | 三角学 | 方位测距、周期解全集 | 5、4 | 1、1 |

19 题单答案，7 题多答案；包含数值、表达式、区间、方程、集合、单选和多选。各行的 `source_id` 可追溯到原题。`answer_slots`、`answer_types`、`answer_options` 用于逐栏人工核对；`answer` 是供现有本地评测器读取的文本形式。多栏答案按序编号，当前通用判分器无法可靠对齐时应标记“待复核”，不能将其判成错误。`main.py` 只转发 `problem` 与 `idx`，`source_*` 和答案字段不会送入解题入口。

## 重建与后续诊断

```bash
python benchmarks/build_ugmath_hard26.py --download
```

已下载原始文件时，省略 `--download` 即可离线重建。构建过程**不调用模型 API**。两轮共 12 题已试跑并逐题核对，见 [首轮报告](ugmath_pilot6_report.md)与[第二轮报告](ugmath_level5_report.md)。继续扩测时请换新的结果文件名，保持并发 1；运行会消耗模型配额。每题结合完整 trace 与 `answer_slots` 核对，记录“推理错 / 计算错 / 字段缺失 / 判分器不确定 / 题库疑点 / 超时”及耗时。这个 26 题样本不能换算为官方得分。
