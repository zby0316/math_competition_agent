## 三、BUG / 缺陷 / 死代码排查结果

### 本轮修复
1. **Prompt 转义污染（真缺陷）**：`REASONING_PROMPT` 里 `\rfloor` 单反斜杠被
   Python 转成回车符（`\r`），污染送给模型的提示词。已修为双反斜杠，
   全部模板控制字符扫描归 0。
2. **死变量**：`playoff_node.py` 的 `max_seconds` 定义未用，已删。

### 排查结论（vulture 静态分析 + 转义扫描 + 编译检查）
- **无真实死代码**：vulture 报告的均为误判（FastMCP 装饰器注册的
  `execute_python_tool`、TypedDict 的字段声明）。
- **无编译错误/警告**（SyntaxWarning 已随转义修复消除）。
- **72 项测试连跑 3 次全绿**（1 次偶发 flaky 后稳定，为故障注入测试的时序性）。

### 已知边界（非 bug，诚实记录）
- 组合计数/个别题意理解是 Intern-S2 能力边界（双路一致错，非链路缺陷）；
- 证明/概念题的 playoff 返回 INCONCLUSIVE（无法机械核验，退回语义仲裁）。
