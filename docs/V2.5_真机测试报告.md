## 三、关键发现（对官方预估的意义）

1. **sympy 事前短路命中率仅 1/112（1%）**——题集为自然语言叙述，pre_solver
   正则只认裸算式（`a^b mod m`/`\int`），识别不到"求 2^100 除以 13 的余数"
   这类自然语言形态 → 全部落回 LLM。**V2.5a 预想的"榜一式 sympy 秒解"在
   自然语言题集上基本未兑现**，这也是平均单题仍有 66.5s 的原因。
2. **本地正确率不可线性外推官方**：V2.4 经验（本地 98% → 官方 60%）。V2.5
   本地 ~94%，按同口径预估官方 **59-63 分区间**，主要提升来自截断根治
   （0 error/invalid）而非 sympy 短路（1% 命中）。
3. **判分口径差异**：本地判分脚本对近似值/分数等价偏严（官方"数值等价"更宽），
   本地评估存在低估可能。

## 四、修复方案（按优先级）

| # | 问题 | 修复 |
|---|---|---|
| P0 | sympy 短路 1% 命中率 | 扩展 `_congruence`/`_modular_power`/`_evaluate` 的自然语言模式（"除以 N 的余数"/"的 N 次幂"/"求 X 的导数"）；或 python_agent sympy 验证结果在交叉验证后反哺成稿 |
| P0 | sympy 原语泄漏进答案（idx=46） | 成稿前清洗 `Limit(`/`Piecewise(`/`oo` 等 sympy 原语，或对 sympy 结果统一 `_format` 后再给 LLM 解读 |
| P1 | 判分脚本近似值口径 | grade_llm prompt 加数值容差条款（相对误差 <1% 判 correct/partial） |
| P1 | 题集标准答案验证 | 出题脚本答案加 sympy/穷举自动验证（本次 2 道标准答案错误暴露） |
| P2 | 题目表述歧义（idx=82） | 出题避免"在 X 处展开（绕 Y 环域）"类矛盾表述 |
