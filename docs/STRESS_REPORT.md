## 三、压测抓到的真问题与修复（全部带回归测试）

### Bug 1（最重要）：contradict 假证据绕过裁决
**实证**：idx=30（CRT 题）推理答 423（对）、Python 答 803（错）且自报 contradict。
原链路：contradict 直接仲裁（绕过 playoff），且 coordinator 证据闸门强行采信
Python 错值 → 输出错答 803。
**修复**：①contradict 分支计算题先送 playoff 代回复算裁决（戳破假证据）；
②coordinator 证据闸门在 playoff decisive 后豁免。
**验证**：重跑 idx=30 从错到对（423 ✓）；回归 `test_integration_contradict` 4 项。

### Bug 2：matcher 系统性弱点（structured_indeterminate 占 50%）
**实证**：推理侧给方程形答案（`$\int_0^\infty xe^{-x}dx=1$`）、程序侧给裸值（`1`），
匹配器判不了全推给仲裁（仲裁率 75%）。
**修复**：三形态方程答案剥离（`\text{tr}(A^3)=48` / `y(x)=(1+x)e^{-x}` /
`$\sum...=1$` 取右端），花括号无 LaTeX 命令时转括号。10 组真实答案对 10/10 正确。

### Bug 3：Critic 修复回路脏状态
重算后陈旧 `answer_locked` 会跳过洁净度闸门 → 修复（新 match 强制解锁）。

### Bug 4（启元移植 P0）：判断题系统性偏"否"
移植双向确认：结论→温度0独立自证（理由/反例）→一致采纳/反向温度0重解。
仅 true_false 题型触发，零其余成本。

### Bug 5（启元移植 P1）：推导矛盾自检融入 Critic
推理链内同变量两值（x=3 又 x=5）→ 自相矛盾按 calc_error 触发定向修复。
Fraction 归一+假设/多解/枚举排除，零 API。
