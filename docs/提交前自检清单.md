# 提交前自检清单（AtomGit 评测）

> 依据 2026-07-16 AtomGit 切换公告、2026-07-14 FAQ 与 2026-08-12 判分规则更新整理。
> 每次点击"提交作品"前逐条核对。

## A. 仓库与平台

- [ ] 已在 AtomGit 赛事页面完成报名、组队，参赛仓库建在队伍**新建 Git 组织**下
- [ ] 作品页面已绑定正确仓库；本地已推送 `main` 分支（评测拉取最新 main）
- [ ] 已在作品页面点击"**提交作品**"（仅推送代码不会进入评测）
- [ ] 评测批次：每天 12:00 / 24:00 两个固定时间；每天最多 2 次、每周最多 10 次
- [ ] 批次开始前完成最终推送，拉取期间保持 main 稳定

## B. 接口规范（零分高危项）

- [ ] 根目录存在 `user_agent.py`
- [ ] `ReasoningAgent` 类存在，构造函数接受 `client`（平台注入，不硬编码 API key）
- [ ] `solve(self, problem: str, metadata: dict) -> dict` 签名正确、不抛异常
- [ ] 返回 dict 可 JSON 序列化，`final_response` 为非空字符串
- [ ] 无 `ModuleNotFoundError`：所有 import 的包都在 `requirements.txt` 中声明
- [ ] 不依赖本地绝对路径、私有文件、未声明资源
- [ ] 无硬编码密钥、无规避评测限制的逻辑

## C. 运行时约束（2026-08-12 官方规则更新）

- [ ] **并发 3**：平台统一管控，本地工具用 `--concurrency 3` 对齐验证
- [ ] **单题最长 20 分钟**：`config.py` 中 `problem_time_budget_s=1200`
- [ ] **全卷 6 小时**：`paper_total_seconds=21600`，PaperPacer 预算池保障
      112 题全卷完成（超时未答不计分）
- [ ] 不调用任何非官方在线 API / 外部模型（含"只用于生成提示词"的也不行）
- [ ] 不依赖 Lean 4 / elan / mathlib 等非 Python 工具链
- [ ] 运行时不联网下载资源（离线 RAG 资料随仓库提交）
- [ ] Linux Docker 环境可运行（Windows 下 `sys`/`resource` 已有降级处理）
