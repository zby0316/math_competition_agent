# 提交前自检清单（AtomGit 评测）

> 依据 2026-07-16 AtomGit 切换公告、2026-07-14 FAQ 与判分规则更新整理。
> 每次点击"提交作品"前逐条核对。

## A. 仓库与平台

- [ ] 已在 AtomGit 赛事页面完成报名、组队，参赛仓库建在队伍**新建 Git 组织**下
- [ ] 作品页面已绑定正确仓库；本地已推送 `main` 分支（评测拉取最新 main）
- [ ] 已在作品页面点击"**提交作品**"（仅推送代码不会进入评测）
- [ ] 评测批次：每天 12:00 / 24:00 两个固定时间；每天最多 2 次、每周最多 10 次
- [ ] 批次开始前完成最终推送，拉取期间保持 main 稳定

## B. 接口规范（零分高危项）

- [ ] 根目录存在 `user_agent.py`
- [ ] `ReasoningAgent` 类存在，构造函数接受 `client`（平台注入，不硬编码 API key）
- [ ] `solve(self, problem: str, metadata: dict) -> dict` 签名正确、不抛异常
- [ ] 返回 dict 可 JSON 序列化，`final_response` 为非空字符串
- [ ] 无 `ModuleNotFoundError`：所有 import 的包都在 `requirements.txt` 中声明
- [ ] 不依赖本地绝对路径、私有文件、未声明资源
- [ ] 无硬编码密钥、无规避评测限制的逻辑

## C. 运行时约束

- [ ] 不调用任何非官方在线 API / 外部模型（含"只用于生成提示词"的也不行）
- [ ] 不依赖 Lean 4 / elan / mathlib 等非 Python 工具链
- [ ] 运行时不联网下载资源（离线 RAG 资料随仓库提交）
- [ ] 单题最长 20 分钟；全卷 6 小时（我们的难度软预算已按此优化）
- [ ] Linux Docker 环境可运行（Windows 下 `sys`/`resource` 已有降级处理）

## D. 本地验证（提交前必跑）

```bash
pip install -r requirements.txt
python -B -m unittest discover -s tests -v      # 32 项全绿
export INTERN_API_KEY="sk-..."
python main.py --input_file sample.jsonl --output_dir smoke_outputs   # 真实 API 冒烟
```

- [ ] 单元测试全部通过
- [ ] 真实 API 冒烟至少 3 题（含 1 道填空/选择、1 道计算、1 道证明），
      检查输出 JSON 的 `status == "success"` 且 `final_response` 非空、无碎片
- [ ] 检查 trace 中无 API key 等敏感信息

## E. 材料归档（邮件提交 changshuai@pjlab.org.cn）

- [ ] 技术方案文档（PDF，由 `docs/技术方案文档.md` 导出）
- [ ] 日志与结果文件（JSON）
- [ ] 源代码 zip（排除 outputs/logs/__pycache__/.env）
- [ ] 报名系统审核通过的参赛报名表
- [ ] 压缩包命名：`单位-姓名-作品名称-联系电话.zip`
