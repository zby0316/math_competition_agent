## B. 接口规范（零分高危项）

- [ ] 根目录存在 `user_agent.py`
- [ ] `ReasoningAgent` 类存在，构造函数接受 `client`（平台注入，不硬编码 API key）
- [ ] `solve(self, problem: str, metadata: dict) -> dict` 签名正确、不抛异常
- [ ] 返回 dict 可 JSON 序列化，`final_response` 为非空字符串
- [ ] 无 `ModuleNotFoundError`：所有 import 的包都在 `requirements.txt` 中声明
  - [ ] sympy 已在 `requirements.txt` 声明（官方明确允许本地符号计算库）
- [ ] 不依赖本地绝对路径、私有文件、未声明资源
- [ ] 无硬编码密钥、无规避评测限制的逻辑
- [ ] 不读取注入 client 的内部属性（只依赖 `client.chat(messages, temperature, max_tokens)` 公开约定）
