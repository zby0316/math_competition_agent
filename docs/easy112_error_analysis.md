# easy112 错题归因报告（20 题）

- 实验：V2.5+10项修复，官方 easy 带（1.0–3.5）112 题，Intern-S 判分
- 结果：92/112 = 82.1% 正确，20 错
- 判分口径：Intern-S LLM 语义判分（与官方 Judger 同口径）

---

## 二、修正后的真实正确率

- 名义 92/112 = 82.1%
- **+idx 103（判分误判，实对）→ 93/112 = 83.0%**
- idx 30（题面缺图）与 idx 63（答案存疑）属于口径噪声，官方环境表现可能更好

---

## 三、结论：需要加强的 4 个方向（按错题占比）

| 优先级 | 方向 | 覆盖错题 | 手段 |
|---|---|---|---|
| **P0** | **确定性计算覆盖（9/20 题）** | 45% | 移植 det_solver（15 管线）+ easy/medium 计算题 Python 主解强制复算——枚举/DP/符号计算直接算对，不让 LLM 心算 |
| **P1** | **解集完整性校验（3/20 题）** | 15% | "Find all/最小/保证"类题：Python 枚举对照 + 解数检查（counting_guard 扩展为 solution_completeness_guard） |
| **P1** | **题意目标提取与方向校验（5/20 题）** | 25% | ① 比值题方向规范化（form_align 扩展：a:b 与 b:a 判定）；② "不能等于/选项语义"类题强制先列选项语义；③ 图依赖题识别并给出可判分的文本化推理 |
| **P2** | **表达式化简输出（1/20 题）** | 5% | 最终答案含 acos/asin/sqrt 复合表达式时尝试数值化简或 simplify（减少判分器误判） |

---

## 四、预期收益

- 若 P0（det_solver）落地：9 题计算错中估 5-7 题可救 → **82% → 87-88%**
- 若 P0+P1 全落地：93% 名义 → **90% 上下（官方口径）**
- 剩余 ~10%（题意特殊/图依赖题）是模型+题面信息上限，机制难救
