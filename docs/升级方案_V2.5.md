# V2.5 升级方案：确定性计算 × 多智能体架构

> 目标：把榜一（80.36 / 90 题）的"确定性计算"三件套，嫁接到我们已验证的
> LangGraph 多智能体架构上，**不推倒重来**。预期 66 → 72~78 题。

## 一、定位：我们和榜一的差距到底在哪

榜一代码（Shusheng_ChallengeCup_2026）实测解析后，结论是**架构复杂度我们反而更高**，
真正的差距在"谁来做计算和验证"：

| 维度 | 我们（66 题） | 榜一（90 题） |
|---|---|---|
| 计算 | LLM 心算（易错） | **sympy 事前直接解**，能解就跳过 LLM |
| 验证 | LLM 查 LLM（同源偏差） | **sympy 硬校验**（tool_status pass/conflict） |
| 候选选择 | LLM 语义仲裁 | **确定性规则评分**（complete/shape/tool 一致性） |
| 答案形态 | answer_formatter 较简单 | **render_answer**（按 question_kind 句子化） |

我们已有的、榜一没有的：双路径异构推理、交叉验证、确定性复算季后赛、过程审计、
18 领域知识库、PaperPacer 全卷节奏、截断三层防线、针对官方题集的定向 bug 防护
（F₂ 值域聚合 / 第 k 大差一 / 开区间端点可达性 / 可行性+计数双问项）。

**V2.5 = 榜一的确定性计算 + 我们的多智能体 + 知识库 + 工程韧性。**

## 二、三条主线

### 主线 1：sympy 事前直接解（最大增量，估 +3~5 题）

榜一 `tools/sympy_tool.py` 的 `hints_for`：识别**无歧义**数学子问题
（算术 / 同余 ax≡b(mod m) / 模幂 a^b mod m / 导数 / 积分 / 极限 / 方程 / 矩阵），
sympy 直接算；解出完整目标且非 hard → 跳过 LLM 直接出答案。

- 我们已有 `PythonMCPClient` + `execute_python`（sympy 环境 + 安全扫描 + 隔离齐全），
  缺的只是"事前识别 + 直接解 + 跳过路由"这一层。
- 落地：新建 `utils/sympy_pre_solver.py`（移植 hints_for），在 `classifier_node`
  解析完题型后调用，结果写入 state（`sympy_hints` / `sympy_whole_answer`）；
  若 `sympy_whole_answer` 存在且难度非 hard，`solving` 子图把它作为最高置信候选。

### 主线 2：sympy 硬校验（确定性验证，估 +2~3 题）

候选答案 vs sympy 结果做**数学等价比对**（sympy `simplify(左 - 右) == 0`），
一致加分、冲突减分。替代部分 LLM 互查（cross_validator/仲裁都是模型查模型）。

- 落地：新建 `utils/sympy_equivalence.py`（移植榜一 `math_equivalence` 的符号等价部分），
  在 `cross_validator_node` / `playoff_node` 增加确定性校验维度。
- 合规边界：只用于**候选排序**（选一不选二），不用于**判分**（判对错）——
  判对错仍是官方 judger 职责，不碰"禁止本地判分器"红线。

### 主线 3：answer_frame 答案形态渲染（估 +1~2 题）

榜一 `_render_answer` 把裸数值渲染成判分期望形态：
"所求数量为16个。" / "小明14岁。" / "是。" / "x=1 或 x=2"。

- 我们 `problem_profile` 已有 question_mode，缺的是 `question_kind`
  （数量/年龄/概率/判断句/根/区间）识别 + 对应渲染。
- 落地：增强 `problem_profile.py`（加 question_kind 探测）+ `answer_formatter.py`
  （加 `_render_answer` 句子化），在 `coordinator_node` 收尾时套用。

## 五、合规红线（务必守住）

1. sympy 等价/校验只用于**候选选择**，绝不用于**判分**（判分仍是官方 judger）。
2. sympy 只做"无歧义式子"的确定性计算，解析不了就交给 LLM（榜一同款保守策略）。
3. 不新增"同 prompt 重复采样选答案"（官方明令禁止简单 rollout）；sympy 是确定性
   计算，与 rollout 无关。
4. 保留现有"评分一律 LLM 判分"的本地评测口径，sympy 校验不替代本地 grade_llm。
